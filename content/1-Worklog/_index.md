During my internship, I spent 12 weeks, from 08/08/2026 to 14/11/2026, learning and practicing AWS services, while also participating in building a group project (workshop) titled Building a Backup and Recovery System for a Web Server on AWS.

In the first 8 weeks, I focused on learning foundational knowledge and practicing with the following AWS services: Account Management, AWS IAM, AWS Budgets, Amazon EC2, Amazon EBS, Amazon RDS, Amazon Route 53, Amazon CloudWatch, and AWS Backup.

In the remaining 4 weeks, I explored Serverless architecture (AWS Lambda, API Gateway), Migration solutions, and advanced networking. At the same time, I applied this knowledge to develop, integrate, and test the group project. I also focused on reviewing, fixing bugs, writing the internship report, and publishing the worklog website, finalizing the final product on 14/11/2026.

*Week 4 (05/09 – 12/09/2026):* [Deploy Amazon EC2 virtual servers and install a Web Server.](1.4-week-4-worklog/)
