# Mini setup FCAJ 
This session was extremely special as it brought 3 highly practical sessions presented by:

- Nguyễn Thành Trung – Software Engineer | FPT Software
Topic: Security when Chatbot calls LLM API

When integrating LLMs into Chatbots, security doesn't just stop at hiding API Keys. Mr. Trung deeply analyzed the risks (such as Prompt Injection, data leaks) and how to control data flow. The biggest lesson is to design a secure AI architecture from the very beginning, with built-in guardrails, instead of just focusing on features.

- Phạm Minh Quang – Cloud Engineer | NTQ Solution
Topic: Migration Journey: From scattered Accounts to Landing Zone

This is a very "headache-inducing" topic for enterprises as their AWS systems grow massive. Mr. Quang shared the roadmap for standardizing Multi-Account management through a Landing Zone. Setting up centralized authorization, cost control, and security makes scaling the system much easier.

- Vũ Thế Huy – Data Engineer | Rikkiesoft
Topic: Beyond Parquet: Apache Iceberg on AWS

Parquet is very familiar in Data Lakes, but when data needs continuous updates (upsert/delete), Parquet reveals its weaknesses. Mr. Huy pointed out how Apache Iceberg solves this problem: supporting Schema Evolution, Time Travel, and excellent data versioning. This is the perfect piece to build a modern Data Lake on AWS.

3 sessions, 3 different areas, but all aimed at a common goal: Building secure, scalable, and production-ready Cloud & AI systems. The AWS office space is very nice, the speakers shared enthusiastically, and the Q&A on Quizizz was incredibly lively.
